## en

### New

- Added opt-in end-to-end encrypted synchronization through iCloud Drive, WebDAV, S3-compatible storage, or a local folder. Credentials and keys stay in Keychain, while conflict-resistant merging keeps concurrent and offline devices convergent.
- The main window, menu bar panel, and Quick Paste now share a complete item context menu. Quick Paste also supports configurable keyboard-driven menu navigation and direct copy actions for single or ordered multi-selection.
- Tags and folders are now visible on grid cards across all history surfaces and in menu bar list rows. Their compact metadata rails use available card width before collapsing overflow into a count.
- Sensitive text previews remain redacted by default and can reveal the original content temporarily inside the app. Raw values stay in memory and are hidden again when the preview closes or the app loses focus.
- Color literals in Hex, RGB, HSL, and HSV formats now receive consistent previews across the main window, menu bar, and Quick Paste: list rows show a swatch with the original text, while grid cards show the full color, original value, and a Color Value badge.

### Improvements and Fixes

- Video preview settings now apply to manual previews. First-frame mode and muted playback use the app's AVKit preview, while unmuted video playback retains native Quick Look.
- Added tag editing to the menu bar and Quick Paste context menus. The editor lists existing tags, stages multiple selections locally, supports the two-step Return workflow, and can cancel all pending changes.
- Menu bar tag editing now stays inside the menu window, preventing macOS from collapsing the panel when an existing tag is clicked.
- Main-window grid cards expose a cleaner, consistent primary action set while retaining secondary commands in the shared context menu.
- Quick Paste supports Command-C copy feedback in list and grid layouts, preserves multi-selection order, and improves horizontal grid navigation across groups.
- Restored release compatibility with the Xcode 16.2 runner and its supported KeyboardShortcuts package version.

## zh

### 新功能

- 新增可选的端到端加密同步，支持 iCloud 云盘、WebDAV、S3 兼容存储和本地文件夹。凭据与密钥保存在钥匙串中，并通过可抗冲突的合并机制让并发与离线设备最终收敛。
- 主窗口、菜单栏面板与快速粘贴面板现在共用完整的条目右键菜单。快速粘贴同时支持可配置的全键盘菜单导航，以及单条或按选择顺序批量复制。
- 所有历史界面的网格卡片以及菜单栏列表现在都会展示标签和文件夹；紧凑信息条会先利用卡片可用宽度，仅在真正溢出时折叠为数量提示。
- 敏感文本预览默认保持脱敏，并可在应用内临时显示原文。原始内容仅驻留内存，关闭预览或应用失焦后会立即恢复脱敏。
- Hex、RGB、HSL、HSV 等格式的色值现在会在主窗口、菜单栏和快速粘贴中统一展示：列表显示色块与原文，网格显示整块颜色、原始色值及「色值」标签。

### 改进与修复

- 视频预览设置现在会作用于手动预览。首帧模式与静音播放使用应用内 AVKit 预览，非静音视频播放继续使用系统速览。
- 菜单栏与快速粘贴右键菜单新增标签编辑。编辑器可展示已有标签、本地暂存多项选择、使用两阶段回车流程，并可取消本次全部修改。
- 菜单栏标签编辑改为窗口内覆盖层，修复点击已有标签时 macOS 自动收起菜单栏面板的问题。
- 主窗口网格卡片统一并精简了常用操作，次级功能仍可从共享右键菜单访问。
- 快速粘贴在列表与网格布局中支持 Command-C 复制反馈、保持多选顺序，并优化跨分组的横向网格导航。
- 恢复与 Xcode 16.2 发布环境及其可用 KeyboardShortcuts 版本的兼容性。
