## en

### New

- List and grid layouts across ClipTrace: the main window now has a responsive grid with four-direction keyboard navigation, while Quick Paste and the menu bar panel offer independently configurable two-column grids in Settings. Grid cards use the content area directly, preserve image aspect ratios without cropping, and overlay image names in place.
- Text, URL, and rich-text clips can now be Base64 encoded or decoded from the row action bar and context menu.
- A first-run main-window tour introduces search, filters, groups, snippets, multi-select, cards, capture controls, and Quick Paste.
- Available updates are surfaced proactively in the app, and update-triggered relaunches no longer show the normal quit confirmation.

### Improvements and Fixes

- Hover tips now use floating panels so they are not clipped by parent views.
- Group strips accept horizontal scrolling from any mouse-wheel direction, and Quick Paste surfaces align consistently.
- Quick Paste dwell previews match the panel material correctly.
- The macOS 26 Dock icon is rendered directly in the Dock tile to avoid an unwanted white backing plate.
- Added `skipLegacyStoreScan` as an escape hatch for machines where probing legacy app containers is blocked by macOS privacy controls.

## zh

### 新功能

- 剪迹全面支持列表与网格布局：主窗口新增自适应网格与四向键盘导航；快速粘贴和菜单栏面板可在设置中分别启用双列网格。网格卡片直接利用内容区域，图片保持原始宽高比且不裁切，并在图片内以浮层展示名称。
- 文本、链接和富文本条目可从悬停操作栏或右键菜单进行 Base64 编码与解码。
- 主窗口新增首次使用导览，依次介绍搜索、筛选、分组、片段、多选、卡片、监听控制与快速粘贴。
- 应用会主动提示可用更新；更新安装触发的重启不再弹出普通退出确认。

### 改进与修复

- 悬浮提示改用独立浮动面板，不再被父视图裁切。
- 分组条支持任意方向滚轮横向滚动，快速粘贴面板的表面对齐更加统一。
- 快速粘贴的停留预览正确适配面板自身材质。
- macOS 26 Dock 图标改为 Dock tile 自绘，移除多余的白色底板。
- 新增 `skipLegacyStoreScan` 逃生开关，用于绕过被 macOS 隐私控制阻塞的旧容器扫描。
