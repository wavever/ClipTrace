## en

### New

- Search is back in the menu bar panel and the Quick Paste panel, and it is keyboard-first: press ⌘F in any of the three surfaces (main window, menu bar, Quick Paste) to jump into the search field, and press Esc twice to leave search (first press clears the query, second returns focus to the list). In Quick Paste you can keep typing while ↑/↓ move the highlight and ⏎ pastes the focused match — no mouse needed.
- Content protection now uses one unified rule list: the built-in phone-number and app-key detectors sit alongside your own keyword/regex rules, and every rule can be edited or toggled. Regex rules with capture groups mask only the sensitive part (labels and quotes stay readable). Existing settings migrate automatically.
- The OCR window gained a recognized-text side panel with Plain and Structured tabs: plain text follows reading order, while structured mode reconstructs indentation and column layout in monospace for tables and code screenshots.
- The update reminder is now a warm paper pill next to the capture toggle (main window and menu bar panel); one click starts the update, and "Skip This Version" dismisses it.

### Performance

- Panel search runs bounded SQLite queries with typing debounce, so searching stays smooth even on very large histories (this is what made it possible to re-enable menu bar search).
- Image capture decoding and re-encoding moved off the main thread — copying TIFF or oversized images no longer freezes the UI.
- Masking results are cached for list rendering, batch operations (delete group, delete all, empty trash) no longer pull image data into memory, and background timers now use tolerance for lower idle power draw.

### Fixes

- Fixed a crash when deleting a rule row in Settings while its text field still had focus.
- Opening the main window or Settings from the menu bar panel now switches to the window's Space instead of staying on a fullscreen app's Space.

## zh

### 新功能

- 菜单栏面板与快速粘贴面板重新加入搜索，并全面支持键盘操作：三处面板（主窗口、菜单栏、快速粘贴）均可按 ⌘F 直接聚焦搜索框，连按两次 Esc 退出搜索（第一次清空查询，第二次焦点回到列表）。快速粘贴中输入时 ↑/↓ 仍可移动高亮、⏎ 直接粘贴当前项——全程无需鼠标。
- 内容保护改为统一规则列表：内置的手机号 / App Key 识别与自定义关键词 / 正则规则同列，均可编辑、可停用；含捕获组的正则只脱敏敏感部分（标签、引号保持可读）。旧设置自动迁移。
- OCR 窗口新增识别文本侧栏，提供「纯文本 / 结构化」两种视图：纯文本按阅读顺序输出，结构化模式以等宽字符重建缩进与列布局，适合表格与代码截图。
- 更新提示统一为监听开关旁的暖色纸质 pill（主窗口与菜单栏面板），点击即可开始更新，「跳过此版本」会同时清除提示。

### 性能

- 面板搜索改为有界 SQLite 查询并带输入防抖，超大历史下搜索依然顺滑（菜单栏搜索也因此得以重新启用）。
- 图片捕获的解码 / 重编码移到后台线程，复制 TIFF 或超大图片不再卡住界面。
- 列表渲染的脱敏结果增加缓存；批量操作（删除分组、全部删除、清空垃圾桶）不再把图片数据拉入内存；后台定时器增加容差以降低空闲功耗。

### 修复

- 修复在设置页删除规则行时（文本框仍处于聚焦状态）可能出现的闪退。
- 从菜单栏面板打开主窗口 / 设置时会切换到窗口所在空间，不再停留在全屏应用的空间。
