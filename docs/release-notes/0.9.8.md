## en

### Reliability

- Fixed a serious history recovery issue on macOS 26: Clipth now pins its SwiftData store to a stable app-owned path and recovers records from older default-store locations on launch.
- The recovery keeps the old database in place and copies the store plus its WAL/SHM sidecars into the new location, so existing clipboard history is not overwritten.
- The MCP server now opens the same shared store as the main app, keeping AI-tool access aligned with the UI.

### App

- Added macOS widgets for clipboard data and copy activity.
- Added a confirm-before-quit option to avoid accidentally stopping clipboard capture.
- Added a pause-monitoring control for temporarily suspending capture while keeping history browsable.

## zh

### 可靠性

- 修复 macOS 26 上严重的历史记录恢复问题：剪迹现在会把 SwiftData 历史库固定到稳定的应用目录，并在启动时从旧默认位置恢复记录。
- 恢复过程会保留旧数据库，只复制主库和 WAL/SHM 侧车文件到新位置，避免覆盖已有剪贴板历史。
- MCP server 现在和主应用打开同一个共享历史库，AI 工具访问到的数据会和界面保持一致。

### 应用

- 新增 macOS 小组件，可查看剪贴板数据和复制活跃统计。
- 新增退出前确认，避免误操作导致剪贴板捕获停止。
- 新增暂停监控控制，可以临时停止捕获，同时继续浏览已有历史。
